# RustyCLI

[![CI](https://github.com/tanishq0421/RustyCLI/actions/workflows/ci.yml/badge.svg)](https://github.com/tanishq0421/RustyCLI/actions/workflows/ci.yml)
![MSRV](https://img.shields.io/badge/MSRV-1.74-blue)
![License](https://img.shields.io/badge/license-MIT-green)

A Unix-like shell written in Rust: pipelines, redirection, job control, aliases, glob expansion, tab completion, and a git-aware prompt. Designed as a small but production-shaped codebase — typed `ParseError`s, async-signal-safe SIGINT handling, integration-tested via `assert_cmd`, fuzz-tested with `cargo-fuzz`.

![demo](docs/demo.gif)

## Features

- **Three execution modes**: interactive REPL, one-shot `-c "cmd"`, or `script.sh` file.
- **Pipelines & redirection**: `|`, `>`, `>>`, `<` with proper fd management. Multi-statement lines via `;`.
- **Background jobs**: `&` to background, `jobs`/`fg <id>` to inspect and resume.
- **Variable expansion**: `$VAR` resolves against the live environment, applied per-pipeline so `export X=v; echo $X` works.
- **Aliases via `~/.rustyrc`**: bash-style `alias ll='ls -la'`, with cycle-safe recursive expansion.
- **Glob expansion**: `*.rs`, `?`, `[abc]` patterns; quoted args bypass globbing (bash semantics).
- **Tab completion**: rustyline `Completer` for builtins, `$ENV_VAR`s, and filesystem paths.
- **Git-aware colored prompt**: `~/path branch* ❯` via libgit2 (no shell-out).
- **Async-signal-safe signal handling**: `SIGINT` flips an `AtomicBool` and writes a byte via `libc::write` — no UB-prone `println!` in a signal context.
- **Typed parser errors**: `ParseError` via `thiserror`, surfaced to the user without crashing the shell.
- **Tested**: 45 unit + integration tests (`assert_cmd`/`predicates`) and a `cargo-fuzz` target on the parser.
- **CI**: GitHub Actions matrix — `fmt`, `clippy -D warnings`, build + test on Linux & macOS, stable & MSRV.

### Architecture at a glance

The shell is split along three axes:

1. **Frontend (string → AST)** — `parser.rs` tokenizes and produces a flat
   `Vec<Pipeline>` where each `Pipeline` is a `Vec<Command>` joined by `|`,
   plus an optional `&` background flag. Errors are typed via `ParseError`
   (`thiserror`).

2. **Middleware (AST → AST)** — applied in `runner::dispatch`:
   - `expand_variables` resolves `$VAR` against the live `Environment`.
   - `AliasTable::expand_pipeline` rewrites the head token of each stage.
   - `glob_expand::expand` fans out `*.rs`-style args.

3. **Backend (AST → processes)** — `executor.rs` forks one child per pipeline
   stage, wires `n-1` pipes, applies per-stage redirections, and waits.
   Builtins short-circuit in the parent with `RedirectGuard` saving/restoring
   stdio fds so `echo hi > file` works without a fork.

`lib.rs` exposes all of this so `tests/` and `fuzz/` can reach the parser
and runner without going through the CLI.

## Installation

### Prerequisites

- **Rust**: Ensure you have Rust installed. You can install Rust using [rustup](https://www.rust-lang.org/tools/install).

### Clone the Repository

```bash
git clone https://github.com/tanishq0421/RustyCLI.git
cd RustyCLI
```

### Build the Project
```bash
cargo build              # debug
cargo build --release    # optimized
```

### Task wrapper (`run.sh`)

A small bash wrapper exposes the common workflows so you don't have to remember every cargo invocation:

```bash
./run.sh build        # cargo build
./run.sh release      # cargo build --release
./run.sh run          # cargo run (interactive)
./run.sh test         # cargo test
./run.sh fmt          # cargo fmt
./run.sh clippy       # cargo clippy -- -D warnings
./run.sh install      # cargo install --path .
./run.sh all          # fmt + clippy + test + release build
```

### Running the Shell

Three modes:

```bash
# 1. Interactive REPL
cargo run

# 2. One-shot command (-c)
cargo run -- -c "ls src/*.rs | wc -l"

# 3. Script file
cargo run -- path/to/script.sh
```

Use `--norc` to skip loading `~/.rustyrc` on startup.

You can also run the binary directly:

```bash
./target/debug/rustycli
```

## Aliases (`~/.rustyrc`)

On startup, RustyCLI sources `~/.rustyrc`. Supported directives:

```bash
# comments are allowed
alias ll='ls -la'
alias gs="git status"
export EDITOR=vim
```

Aliases are expanded at the head token of each pipeline stage, with cycle detection (16-deep recursion limit).

## Testing & Fuzzing

```bash
# Unit + integration tests
cargo test

# Fuzz the parser (requires nightly + cargo-fuzz)
cargo install cargo-fuzz
cargo +nightly fuzz run parse_input -- -max_total_time=120
```

## Built-in Commands

| Command | Behavior |
|---|---|
| `cd [DIR]` | Change directory. Falls back to `$HOME` when `DIR` is omitted, then `/`. |
| `pwd` | Print the current working directory. |
| `echo [ARGS...]` | Print arguments joined by spaces. |
| `export VAR=VALUE` | Set an environment variable (also propagated to child processes). |
| `unset VAR` | Remove an environment variable. |
| `history` | Print this session's command history. |
| `clear` | Clear the terminal screen. |
| `jobs` | List background jobs. |
| `fg JOB_ID` | Bring a background job to the foreground. |
| `help` | List available builtins. |
| `exit [N]` | Exit the shell with status `N` (default `0`). |

Builtins with redirections (`echo hi > out`) run in the shell process behind a `RedirectGuard` that save/restores stdio fds, so they don't need a fork.


## Environment Variable Expansion
You can use environment variables in your commands by prefixing them with $.

```bash
> export MY_VAR=HelloWorld
> echo $MY_VAR
HelloWorld
```

## Command History
Use the history command to display the list of previously entered commands.

```bash
> ls
> pwd
> history
  1  ls
  2  pwd
  3  history
```

## Signal Handling

`SIGINT` (Ctrl+C) interrupts the current foreground command without killing the shell. The handler is async-signal-safe: it sets an `AtomicBool` and writes a single newline via `libc::write` — no allocation, no buffered I/O, no UB.

At the prompt, Ctrl+C clears the current input line; the shell stays alive. Use Ctrl+D (`EOF`) or `exit` to quit.

## Examples

```bash
# Pipelines + redirection
$ rustycli -c "ls src/*.rs | wc -l > /tmp/count && cat /tmp/count"
16

# Variable + alias expansion in one line (alias defined in ~/.rustyrc)
$ rustycli -c "export NAME=tanishq; greet $NAME"
hello, tanishq

# Background jobs (interactive)
> sleep 30 &
[1] 12347
> jobs
[1] Running PID 12347
> fg 1
Bringing job [1] to foreground

# Append redirection
> echo "First"  > file.txt
> echo "Second" >> file.txt
> cat file.txt
First
Second
```

## Dependencies

See `Cargo.toml` for the authoritative list. Highlights:

- `nix` — `fork`/`execvp`/`pipe`/`waitpid`/`sigaction`
- `rustyline` — line editing, history, `Completer`/`Helper` traits
- `clap` — CLI flag parsing (`-c`, script path, `--norc`)
- `anyhow` + `thiserror` — error handling at boundaries vs. typed module errors
- `glob` — `*.rs`-style expansion
- `git2` — libgit2 bindings for the prompt (no `git` subprocess)
- `owo-colors` — ANSI colors for the prompt
